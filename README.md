# Nebrukaddesar: Mürekkep ve İnci

Turgut Can Koloğlugil'in *Nebrukaddesar* romanından uyarlanan, piksel sanatlı, zar ve kart tabanlı bir rol yapma oyunu. Üç perde: Mermer Zindan, Engerek Kollu ve Son Perde: Ebsar'ın Gözleri.
